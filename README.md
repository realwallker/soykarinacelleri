# Karina Célleri — Portafolio inmobiliario

Sitio web profesional y Linktree avanzado de **Karina Célleri**, orientado a la presentación de proyectos inmobiliarios, contenido digital, episodios de *Primera Piedra Podcast* y contacto directo con potenciales clientes.

## Sitio publicado

- [Versión pública en ChatGPT Sites](https://karina-celleri-maestro.wallkeron60hz.chatgpt.site)
- [Versión en Vercel](https://soykarinacelleri.vercel.app)

## Características

- Experiencia responsive para teléfonos, tablets y computadoras.
- Portafolio interactivo de proyectos residenciales, comerciales y corporativos.
- Galerías optimizadas con imágenes específicas para móvil y escritorio.
- Sección dedicada a *Primera Piedra Podcast* con acceso a YouTube.
- Integración de contenido de Instagram y TikTok.
- Acceso directo a WhatsApp para consultas inmobiliarias.
- Navegación accesible mediante teclado, controles táctiles y preferencias de movimiento reducido.
- Metadatos SEO y vista previa optimizada para compartir en redes sociales.

## Tecnología

- Next.js 16
- React 19
- TypeScript
- CSS personalizado
- Despliegue compatible con Vercel

## Ejecutar localmente

Requiere Node.js 22 o superior.

```bash
npm install
npm run dev
```

El sitio estará disponible en `http://localhost:3000`.

Para verificar la versión de producción:

```bash
npm run build
npm run start
```
